# CURSOR

The site's cursors: a hand drawn in pixels, 16 x 18 px. The site shows them at 2x (32 x 36 px).

| Cursor | On the site | |
|---|---|:-:|
| **`CURSOR-POINTING`** | Everywhere, the default | <img src="CURSOR-POINTING.svg" width="64" alt="Pointing hand"> |
| **`CURSOR-POINTING_HIGHLIGHT`** | Links and buttons | <img src="CURSOR-POINTING_HIGHLIGHT.svg" width="64" alt="Pointing hand, blue"> |
| **`CURSOR-OPEN`** | Over something you can drag: the mascot, the venue globe | <img src="CURSOR-OPEN.svg" width="64" alt="Open hand"> |
| **`CURSOR-CLOSED`** | While dragging it | <img src="CURSOR-CLOSED.svg" width="64" alt="Closed hand"> |

Shown here at 4x.

## FILES

- Every cursor is a `.png` and an `.svg` with the same pixels. The SVG stays sharp at any size.
- The hotspot, the pixel that clicks, is x 1, y 5 from the top left.
